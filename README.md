# earthquake-monitor
A simple command-line Python program that records earthquake magnitudes and classifies each reading by severity.

## Features
- Reads magnitudes entered by the user (enter 0 to quit)
- Classifies each reading: Safe (below 4.0), Warning (4.0 to 5.9), Alert (6.0 and above)
- Input validation: rejects non-numeric, negative, nan and inf values
- Prints a summary on exit: total readings, maximum and average magnitude

## How to Run
Run `python Lesson_11_earthquake_functions.py` in a terminal.
